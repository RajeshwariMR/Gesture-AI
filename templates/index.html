Hello! Welcome to Gesture AI

Gesture AI is a Speech-to-Sign Language Converter using animated avatars. It captures spoken words, transcribes them with AI, and displays matching sign language gestures created using Blender. If a word doesn’t have a sign, it shows the letters one by one. Users can review and edit the text before final output.

How It Works

🎤 Captures speech or typed input
🧠 Converts speech to text using OpenAI Whisper
🎬 On Submit, plays matching sign gestures using JSON mapping
